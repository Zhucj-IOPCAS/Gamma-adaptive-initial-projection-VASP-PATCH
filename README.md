# Gamma-Adaptive Initial Projections for Wannier Functions

A patch set that generates Gamma-adaptive initial projections for Wannier functions through the VASP–Wannier90 interface.

Compatible with **VASP 6.6.0** and **Wannier90 3.1.0**.

## Compatibility

| Software | Version |
| --- | --- |
| VASP | 6.6.0 |
| Wannier90 | 3.1.0 |

## Patch Contents

- `patches/vasp-6.6.0-gamma-adaptive.patch` modifies `src/mlwf.F` and `src/pead.F` in VASP.
- `patches/wannier90-3.1.0-gamma-adaptive.patch` modifies `src/wannier_lib.F90` in Wannier90.

The two patches must be used together.

## Prerequisites

- The unmodified VASP 6.6.0 and Wannier90 3.1.0 source trees compile successfully.
- VASP is built with the standard VASP2WANNIER90 interface enabled.
- Apply the patches in clean Git working trees, or back up any local changes first.

## Installation

### 1. Build Wannier90

Run the following commands from the root of the Wannier90 3.1.0 source tree:

```bash
git apply --check /path/to/patches/wannier90-3.1.0-gamma-adaptive.patch
git apply /path/to/patches/wannier90-3.1.0-gamma-adaptive.patch
make lib
```

### 2. Build VASP

Run the following commands from the root of the VASP 6.6.0 source tree:

```bash
git apply --check /path/to/patches/vasp-6.6.0-gamma-adaptive.patch
git apply /path/to/patches/vasp-6.6.0-gamma-adaptive.patch
make
```

Replace `/path/to` with the absolute path to this patch repository.

If a source tree is not a Git repository, apply the corresponding patch with:

```bash
patch -p1 < PATCH_FILE
```

To reverse an uncommitted patch in a Git working tree, use:

```bash
git apply -R PATCH_FILE
```

## Usage

Enable Gamma-adaptive in `INCAR`:

```text
LGAMMA_ADAPTIVE = .TRUE.
```

All other settings follow the standard VASP2WANNIER90 workflow. A `projections` block is still required in `wannier90.win`, but its contents do not affect the initial projections generated by Gamma-adaptive. For example:

```text
begin projections
random
end projections
```

Wannier90 can also be run in library mode by setting:

```text
LWANNIER_RUN = .TRUE.
```

## Supported Features

- Collinear spin-polarized calculations
- Noncollinear calculations and spin–orbit coupling (SOC)
- Disentanglement (These features have not yet undergone extensive testing. Validate the results with a small test case before using the patch in production calculations.)
- `vasp_gam` is not supported because its real-valued wavefunction storage is incompatible with this patch.
- If needed, use vasp_std for single-point calculations.
